# Santa Cruz Games' - Canvas and Oil

These are substantial parts of the graphics code developed by Santa Cruz Game for the GPAC800/GPL16250-based "Disney Fairies: Tinker Bell and the Lost Treasure" and "Power Rangers: Force In Time" Plug-n-Play motion games published by JAKKS Pacific.

*Canvas* is a sprite framework including a potentially novel sub-2.5bpp compression approach

*Oil* is just a JPEG decoder, with inner loops in µNSP assembly.

Both of these are designed with the GPAC800/GPL16250 architecture in mind, and take advantage of the unusual 8MB SRAM that these two games had available to them.
