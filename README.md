# Santa Cruz Games' - Canvas and Oil

These are substantial parts of the graphics code developed by Santa Cruz Game for the GPL16250-based "Disney Fairies: Tinker Bell and the Lost Treasure" and "Power Rangers: Force In Time" Plug-n-Play motion games published by JAKKS Pacific.

*Canvas* is a sprite framework including a potentially novel sub-4bpp compression approach

*Oil* is just a JPEG coder, with inner loops in assembly.

Both of these are designed with the µNSP architecture in mind, and take advantage of the unusual 8MB SRAM that these two games had available to them.
